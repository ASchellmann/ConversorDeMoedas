# ConversorDeMoedas
Projeto obrigatório de um curso.

Este projeto é uma aplicação simples em Java que permite converter valores entre diferentes moedas utilizando a API ExchangeRate-API, realizado no VScode.

Caso a importação da biblioteca não funcione, é necessario a criação de um arquivo e pasta, .vscode/settings.json, para o funcionamento da biblioteca, contendo:

{
  "java.project.referencedLibraries": [
    "lib/**/*.jar"
  ]
}
